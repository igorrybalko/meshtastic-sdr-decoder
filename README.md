# Meshtastic SDR Decoder

A hobby project exploring the decoding of Meshtastic LoRa packets from SDR recordings using Python.

The goal is to learn how the LoRa physical layer and Meshtastic packet format work, and to experiment with receiving and decoding packets from RTL-SDR IQ data.

## Project status

**Work in progress — experimental and incomplete.**

This is an early prototype, not a finished or universal decoder. Some parts have been tested with specific captures and settings, but decoding may be unreliable with other signals, devices, or radio configurations. Features and interfaces may change as development continues.

## Requirements

- Python
- RTL-SDR-compatible IQ recordings, or compatible SDR hardware for live reception

Additional Python dependencies may be required; see the imports in the source files.

## Disclaimer

This project is intended for learning and experimentation. Successful decoding is not guaranteed. Use radio equipment and frequencies in accordance with local regulations.
